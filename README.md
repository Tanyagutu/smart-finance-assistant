# Smart Finance Assistant 

## Project Overview
This project is a Smart Finance Assistant that is meant to helps users ,young adults and students mainly to be able to understand their spending habits and track them ,using CSV transaction data. It is designed to analyse spending patterns and provide simple financial insights.

# Purpose 

This project is meant to help students and young adults track their spending habits by giving them insights on their finacial habits and their transaction

## Tools & Technologies
- Python (Google Colab)
- Pandas (for data analysis)
- hands-on-ai (for chatbot features as planned)
- Gradio (for user interface as planned)

  ## Sample Inputs and Outputs

### Input
- A CSV file containing transaction data with columns such as:
  - Date
  - Amount
  - Category
  - Description

### Output
- Total spending summary
- Spending by category
- Identification of high spending areas
- Simple financial advice based on spending patterns

## How to Run the Project

1. Open the notebook in Google Colab
2. Upload a CSV file with transaction data
3. Run the notebook cells step by step
4. View the analysis results and insights
